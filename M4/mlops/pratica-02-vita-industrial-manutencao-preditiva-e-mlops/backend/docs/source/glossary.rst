Glossário
=========

.. glossary::

   Ativo
      Bomba ou motor monitorado pelo sistema.

   Datasheet
      Documento sobre origem, composição, uso e limitações dos dados.

   Drift
      Mudança na distribuição dos dados ou na relação entre entrada e resultado.

   Feature set
      Conjunto versionado de variáveis usadas pelo modelo.

   Manifesto
      Registro que conecta dados, código, ambiente, configuração e execução.

   Model Card
      Documento sobre finalidade, métricas, riscos, limitações e uso do modelo.

   Registry
      Cadastro das versões do modelo e de seus estágios operacionais.

   Run
      Execução rastreada de um experimento.

   PSI
      Population Stability Index, usado para comparar distribuições.

   VITA
      Visionary Industrial Technology Architecture, organizada em seis camadas.
