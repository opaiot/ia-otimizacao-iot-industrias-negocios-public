# 4. Cognicao

## Responsabilidade

Avaliar resultados, produzir diagnosticos e transformar saidas dos modelos em
informacao compreensivel para decisao.

## Entradas

Predicoes e modelos candidatos produzidos pela camada Ciberfisica.

## Saidas

- ROC AUC, F1, precisao e recall;
- falsos positivos e falsos negativos;
- custo operacional esperado;
- criterio transparente para selecionar o candidato.

## Evidencias de MLOps

Metricas, criterios de aceitacao, comparacao de candidatos e limites conhecidos.
Melhor acuracia isolada nao significa aprovacao para producao.
