# 5. Configuracao

## Responsabilidade

Disponibilizar os resultados e transformar o conhecimento analitico em recomendacao
operacional controlada.

## Entradas

Risco estimado, limiar aprovado e estado digital do ativo.

## Saidas

- prioridade de atendimento;
- recomendacao para a equipe de manutencao;
- endpoints da API;
- interface para dashboard e sistemas externos.

## Restricao de seguranca

O case nunca desliga equipamentos automaticamente. A API recomenda; uma pessoa
responsavel avalia e decide.

## Evidencias de MLOps

Endpoint, versao do servico, modelo usado, decisao recomendada e log da inferencia.
