# Matriz de responsabilidade

| Atividade | Responsavel | Aprovador | Consultados |
| --- | --- | --- | --- |
| Qualidade dos dados | engenharia de dados | data owner | manutencao e automacao |
| Treinamento | ciencia de dados | model owner | especialista de processo |
| Validacao | ciencia de dados | comite de IA | manutencao e negocio |
| Promocao | MLOps | model owner | seguranca e operacao |
| Monitoramento | MLOps | model owner | manutencao |
| Acao fisica | manutencao | responsavel operacional | seguranca |
| Retirada e rollback | MLOps | model owner | operacao e governanca |

O assistente conversacional nao ocupa nenhum papel de aprovacao e nao pode executar
acoes operacionais.
